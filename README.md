# 📊 Student Marks Analyzer

A Python-based data analysis project that analyzes student academic performance using *Pandas* and visualizes insights using *Matplotlib*.

## 📌 Project Overview

The Student Marks Analyzer takes student marks from a CSV file and performs useful academic analysis.

The project calculates total and average marks, identifies pass/fail students, finds the class topper and best-performing subject, and generates visualizations to understand student performance.

## ✨ Features

- 📂 Read student data from a CSV file
- ➕ Calculate total marks for each student
- 📊 Calculate average marks
- ✅ Identify PASS and FAIL students
- 🏆 Find the class topper
- 📉 Find the lowest-performing student
- 📚 Find the best-performing subject
- 📈 Calculate subject-wise average marks
- 🎯 Count students above the class average
- 📊 Generate different performance visualizations

## 🛠️ Technologies Used

- *Python*
- *Pandas* – Data analysis and CSV handling
- *NumPy* – Numerical operations
- *Matplotlib* – Data visualization

## 📊 Visualizations

The project includes the following charts:

1. Student vs Total Marks
2. PASS vs FAIL Distribution
3. Subject-wise Average Marks
4. Student vs Average Marks
5. Student Performance Across All Subjects
